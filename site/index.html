What changed recently

PR 도구에서
업무 흐름의 Cockpit으로.

최근 릴리스는 더 많은 버튼보다, 앱 밖에서 끊기던 업무 맥락을 안으로 가져오는 데 집중했습니다.

1.30.2 · DASHBOARD

내가 만든 PR은 저장소 경계 밖에서도

팀 등록 여부와 관계없이 현재 GitHub 사용자가 만든 모든 open·Draft PR을 “내 PR”에 표시합니다. 설정과 인프라를 함께 다루는 저장소는 최상단에서 먼저 봅니다.

ALL REPOSOPENDRAFTPINNED CONFIG
1.30.3 · ACTIVITY

모든 백그라운드 작업을 같은 언어로

Jira, Slack, Loki, AI 분석, 지식 관리와 GitHub 작업에도 대상·단계·모델·처리 수치·종료 결과를 남깁니다.

1.30.3 · REVIEW

자동 리뷰는 막지 않고 알려줍니다

보완 필요 판정은 일반 코멘트와 알림으로 남기고 승인을 보류합니다. 자동 REQUEST_CHANGES로 사람의 머지를 막지 않습니다.

1.30.4 · LOCAL RUN

12개 서비스를 실행 전 검증과 함께

CS 8개·29CM 4개 서비스의 JDK, AWS SSO, OneConf와 로컬 인프라 상태를 확인하고 실행합니다.

1.30.5 · AUTO REVIEW

새 커밋은 새 리뷰로 이어집니다

이미 리뷰한 PR도 코드가 바뀌고 내가 다시 리뷰어가 되면 최신 head SHA 기준으로 자동 재리뷰합니다.

1.32 · ALERTS

완료와 재발을 같은 결과에서 구분합니다

현재 표시 이슈의 Done 티켓만 확인하고 과거 로그를 즉시 정리합니다. 완료 이후 로그는 재발로 표시하고 제외·재발 수를 함께 알려줍니다.

자주 묻는 질문

AI 계정이 없어도 사용할 수 있나요?＋

네. GitHub PR 조회, 상태 필터, 상세 확인 등 비AI 기능은 그대로 동작합니다. AI가 필요한 버튼은 비활성 상태와 이유를 표시합니다.

Loki나 Slack 토큰이 없으면 설치가 실패하나요?＋

실패하지 않습니다. 두 연동은 선택 사항이며, 설정하지 않으면 해당 모니터링·알림 기능만 쉬어갑니다.

앱을 닫으면 진행 중 리뷰도 중단되나요?＋

게시형 리뷰는 백그라운드 worker가 소유합니다. 앱을 닫았다 다시 열어도 진행 상태와 종료 결과를 다시 확인할 수 있습니다.

메뉴 막대 아이콘이 보이지 않으면 어떻게 하나요?＋

Spotlight에서 Cockpit을 다시 열면 일반 창으로 접근할 수 있습니다. 메뉴 막대 공간이 부족하면 macOS가 항목을 숨길 수 있습니다.
