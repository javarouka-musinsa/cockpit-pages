A review flight plan

한 번의 리뷰가 지나가는 길

단계가 바뀌어도 같은 PR과 같은 작업 ID를 따라갑니다.

  1. 01
    Collect

    PR 상태 수집

    GitHub의 리뷰, CI, 충돌, Draft 상태를 읽습니다. 비CS·외부 저장소는 필요한 순간에만 불러올 수 있습니다.

    비AI
  2. 02
    Review

    검토 기준 적용

    선택한 AI와 effort, 레포 추가 기준, 누적 지식을 작업 카드에 기록하며 리뷰합니다.

    ✦ AI
  3. 03
    Decide

    사람이 결과 확인

    리뷰 본문과 인라인 코멘트를 확인하고 승인, 변경 요청 또는 사전 리뷰 코멘트 게시를 선택합니다.

    혼합
  4. 04
    Recover

    중단 후에도 이어서

    worker가 요청과 결과를 보존합니다. 앱이나 worker가 다시 시작돼도 실행 정보와 이력을 복구합니다.

    비AI

Local by design

공개 페이지에는 제품 설명만,
업무 데이터는 로컬에.

이 안내 페이지는 예시 데이터로만 구성됩니다. Cockpit의 저장소, PR 정보, 연동 토큰과 작업 이력은 이 페이지로 전송되지 않습니다.

Before takeoff

자주 묻는 질문

AI 계정이 없어도 사용할 수 있나요?＋

네. GitHub PR 조회, 상태 필터, 상세 확인 등 비AI 기능은 그대로 동작합니다. AI가 필요한 버튼은 비활성 상태와 이유를 표시합니다.

Loki나 Slack 토큰이 없으면 설치가 실패하나요?＋

실패하지 않습니다. 두 연동은 선택 사항이며, 설정하지 않으면 해당 모니터링·알림 기능만 쉬어갑니다.

앱을 닫으면 진행 중 리뷰도 중단되나요?＋

게시형 리뷰는 백그라운드 worker가 소유합니다. 앱을 닫았다 다시 열어도 진행 상태와 종료 결과를 다시 확인할 수 있습니다.

메뉴 막대 아이콘이 보이지 않으면 어떻게 하나요?＋

Spotlight에서 Cockpit을 다시 열면 일반 창으로 접근할 수 있습니다. 메뉴 막대 공간이 부족하면 macOS가 항목을 숨길 수 있습니다.
